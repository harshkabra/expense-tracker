# Expense Tracker

A simple Expense Tracker built using Python.

## Project Description

This project is created to practice and understand Python programming concepts by building a simple expense management system.

The system allows users to add, view, search, delete, and calculate expenses.

Each expense contains:

* Expense Name
* Amount
* Category
* Date

## Features

1. Add Expense
2. View Expenses
3. Search Expense
4. Delete Expense
5. Calculate Total Expense
6. Exit
